# Обёртка над Keitaro

Два экрана поверх Keitaro Admin API:

- **Новая кампания** — по имени, гео и офферу создаёт кампанию с двумя потоками:
  первый ловит указанные страны и редиректит на google.com, второй ведёт всех
  остальных на оффер.
- **Редактор офферов** — добавление и удаление офферов в потоках кампании:
  черновик → Push to Keitaro, Cancel, архив удалённых, Bring back, закрепление долей.

Стек: FastAPI + SQLAlchemy (SQLite), React + Vite + TypeScript.

## Настройка

```bash
cp .env.example .env
```

В `.env`:

| Переменная | Что это |
|---|---|
| `KEITARO_URL` | Адрес трекера, без `/admin_api` |
| `KEITARO_API_KEY` | Ключ Admin API |
| `KEITARO_DOMAIN`, `KEITARO_GROUP`, `KEITARO_SOURCE` | Домен, группа и источник для новых кампаний (см. ниже) |
| `CAMPAIGN_NAME_PREFIX` | Префикс имён кампаний, например `test_ivanov_`. Подставляется, если имя с него не начинается |

Домен, группа и источник ищутся в Keitaro по имени и создаются, если их там нет.
Пустое значение — поле кампании не проставляется. Если запись не удалось ни найти,
ни создать (например, у API-ключа нет прав на раздел), кампания создаётся без неё,
а форма показывает предупреждение.

Настройки читаются при старте бэкенда: после правки `.env` его нужно перезапустить.

## Запуск

Нужны Python 3.10+ и Node.js 18+. Бэкенд и фронт запускаются в двух терминалах
из корня проекта.

```bash
# терминал 1: бэкенд — http://127.0.0.1:8000
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

```bash
# терминал 2: фронт — http://localhost:5173 (проксирует /api на бэкенд)
cd frontend
npm install
npm run dev
```

База обёртки — файл `backend/wrapper.db`, создаётся при первом запуске.

## Тесты

```bash
cd backend && .venv/bin/python -m pytest
```

Тесты не ходят в настоящий Keitaro: трекер подменён заглушкой в памяти.

## Создание кампании

- Гео — двухбуквенный код страны; можно несколько через запятую (`MX, AU, RO`).
- Оффер выбирается поиском по названию или ID среди офферов Keitaro.
- Ротация потоков — по позиции: сначала проверяется поток с фильтром по стране.
- Без домена ссылка кампании строится от адреса самого трекера.
- Если кампания создалась, а один из потоков — нет, кампания убирается в архив.

## Как работает редактор

- **Fetch streams from KT** забирает потоки из Keitaro. Потоки без офферов
  показываются только именем. Офферы, которые обёртка знала, но которых в Keitaro
  больше нет (или они там отключены), становятся удалёнными (серыми).
- Любое изменение сначала живёт только в базе обёртки, поток становится жёлтым.
  **Push to Keitaro** публикует его, **Cancel** откатывает всё неопубликованное.
- **Remove** оставляет оффер в архиве с долей 0%, **Bring back** возвращает его.
- Доли — целые проценты с суммой 100. Остаток до 100% после закреплённых делится
  поровну между остальными, лишние проценты достаются первым по порядку (34/33/33).
- **Pin** закрепляет текущую долю оффера: дальнейшие пересчёты её не трогают.
  Чтобы задать свою долю, измените число в поле и нажмите «Закрепить N%» или Enter —
  вручную заданная доля всегда закрепляется. **Unpin** снимает закрепление.
- **View in KT** открывает выбранную кампанию в админке Keitaro.
